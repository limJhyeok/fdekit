# 데이터 대조 항목

파일이 둘 이상이면 아래 항목을 모두 확인하고, 해당 사항이 없으면 "없음"이라고 적는다.

| 기호 | 항목 | 확인 방법 |
|---|---|---|
| 0 | **정면 모순** | 같은 상황에 대해 다른 값·규칙을 말하는 곳. 없으면 "모순 없음"을 [사실]로 명시한다. 문제 설명이 "사람마다 다르다"고 할 때 자료 간 모순 때문이라고 성급히 결론 내리지 않기 위함 |
| A | 한쪽에만 있는 내용 | 규정 문서에는 있는데 FAQ·요약본에는 없는 항목. 요약본은 원래 일부만 담으므로 "빠진 것이 문제인지"는 [가설]로 둔다 |
| B | 근거가 없는 항목 | 파생 문서에만 있고 원본 문서에는 없는 항목. 어느 쪽이 공식인지 질문으로 |
| C | 본문에는 없고 보조 칸에만 있는 정보 | 메모·비고·주석에만 있는 사실이나 조건. 보조 칸의 내용을 종류별(주의사항 / 출처 / 추가 사실 / 적용 조건)로 분류 |
| D | 해석이 갈리는 표현 | 기간 계산(주말 포함?), 횟수·반복 제한, 접수 경로, 같은 대상의 다른 이름, 문제 설명 속 넓은 용어("변경", "관리" 등) |
| E | 버전·신선도 | 작성일, "추후 반영 예정" 같은 문구, 문서 간 참조 관계. 참조 관계는 실제로 참조하는 항목만 적고 전체로 일반화하지 않는다 |
| F | 규모 | 파일 크기, 건수, 항목 수. 도구로 센 값만 |

## 주의
- 대조 결과 표의 '의미'·'영향' 칸에 "오해하기 쉬운", "분쟁이 생기기 쉬운" 같은 판단을 근거 없이 쓰지 않는다.
- 사실상 같은 내용을 표현만 다르게 쓴 경우는 빈 곳으로 분류하지 말고 "표현 차이 [추정]"으로 둔다.
- 한 문서에 있는 조건이 다른 문서의 보조 칸에만 있을 때는 "어느 문서 안에서" 그런지 명시한다.
